# 013 - High Level Architecture (HLD)

## Project

Smart Energy Demand Analytics

---

## Objective

The objective of this architecture is to build an end-to-end Azure Data Engineering solution that ingests data from multiple source systems, processes it using a Medallion Architecture, stores it in a centralized Data Warehouse, and provides business insights through Power BI dashboards.

---

## Source Systems

- Customer Database (Azure SQL Database)
- Billing Database (Azure SQL Database)
- Smart Meter REST API
- Weather REST API
- Tariff Master (CSV)
- Region Master (CSV)

---
